# إتعلم مع آل عبده

لعبة تعليمية مصرية للأطفال، فيها **ميس بسمة** بتشرح كل حاجة باللهجة المصرية وبصوت حقيقي.
من **متجر آل عبده**. متاحة على Google Play (مدفوعة)، وكمان فيه نسخة للكمبيوتر (Windows).

## الأقسام
- الحروف عربي وإنجليزي، والأرقام، والحيوانات، والكتابة بالصباع
- القراءة (الحركات، المقاطع، تركيب الكلمات، الجمل) والإملاء
- القرآن الكريم بتفسير بسيط، والأحاديث، والعبادات (الوضوء، الصلاة، الأذكار، قصص الأنبياء)
- القصص، ومواقف وحلول
- اكتشف العالم، ومهارات الحياة (الساعة، الفلوس، الدكان)
- English Words، ومصر والعالم
- الرياضيات، واختبارات الذكاء، وألعاب التفكير
- ألعاب الجوايز: العربيات، مغامرة القفز، الشطرنج، المزرعة السعيدة، المكعبات، مملكة الحلويات
- درس اليوم، وركن الأهل (رقم سري، تقارير، تحديد وقت اللعب)

## ترتيب الفولدرات
| الفولدر | فيه إيه |
|---|---|
| `src/` | مصدر اللعبة: `base.html` (اللعبة الأساسية) + الأقسام (`mod_*.js` / `mod_*.css`) + سكريبتات الحقن |
| `app/` | اللعبة الجاهزة: `index.html` وملفات الصوت `voice*.js` و`three.min.js` |
| `android/` | مشروع أندرويد (apktool) وكود `MainActivity` |
| `windows/` | كود برنامج الويندوز (Go) |
| `play/` | صور المتجر واللوجو وصفحة سياسة الخصوصية وسكريبت بناء ملف `.aab` |
| `promo-video/` | ملفات عمل فيديو الإعلان |
| `voice-scripts/` | نصوص الجمل اللي اتسجلت بصوت ميس بسمة |

## البناء
```sh
./build.sh            # يبني app/index.html من src
```
- **أندرويد:** انسخ ملفات `app/` لـ `android/proj/assets/`، وبعدين ابني بـ apktool وbundletool ووقّع بمفتاح الرفع (شوف `play/mkaab.sh`).
- **ويندوز:** انسخ ملفات `app/` لـ `windows/`، وبعدين:
  `GOOS=windows GOARCH=amd64 go build -ldflags "-H windowsgui -s -w" -o MissNour.exe .`

> ⚠️ **مفتاح التوقيع (`alabdo-upload.jks`) وكلمة السر بتاعته مش موجودين هنا عن قصد.**
